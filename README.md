<h2>About</h2>
<p>This is a modern, cloud-native, all-in-one Software-as-a-Service (SaaS) platform template, built using Laravel, react.js, tailwindcss, mysql. </p>
<p>Key Features</p>
<ul>
    <li>The authentication layer, however, is intentionally made stateful, managed by Laravel Sanctum's robust, built-in session handling services.</li>
    <li>XSS Mitigation</li>
    <li>CSRF Protection</li>
    <li>SQL Injection Protection</li>
    <li>Separate Backend & Frontend Implementation (Easy for scalability and hosting)</li>
    <li>Modern Admin Template Integration</li>
</ul>
